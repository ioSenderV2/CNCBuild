J17 ribbon is 1:1 to RP23 J24 (alarms on 1,3,4,5,6; GND on 2). Which alarm pin
  lights which RP23 LED is unlabelled in its schematic - electrically one net.
J20 is a skipped reference: on this bench J20 means the RP23's stepper header.
J30-J33 pass straight through to J34-J37, position for position: mist 2P, flood 2P,
  cycle start / feed hold / e-stop / spare 4P, and UART1 4P in TX / RX / 3.3V / GND order.
J40-J44 are 2.54 mm pin headers paralleling each stepper's logic for a Teensy
  controller: GND / Step / Dir / Enable, the Teensy header order. One per axis
  X, Y1, Y2, Z, B.
